# Visual quality review

Use for an existing site or a completed implementation.

## Review
- Inspect the brief, existing design language and rendered pages. Preserve the parts that work.
- Evaluate the first viewport, reading order, navigation and clarity of the primary action.
- Check type scale, line length, contrast, alignment, spacing rhythm, image crops, consistency and empty space.
- Inspect at 375, 768 and 1440 CSS pixels plus relevant intermediate widths. Look for wrapping, horizontal overflow, clipped text and awkward transitions.
- Check keyboard navigation, focus indicators, semantic labels, readable controls, contrast and motion preferences against WCAG AA.
- Check normal, hover, focus, loading, validation, error and success states where relevant.
- Verify links, form behavior, localized copy and consent preferences using authorized test paths. Use test data for submissions.
- Identify evidence from rendered views and available accessibility or performance reports. Distinguish measured failures from subjective improvements.

## Prioritize
Classify findings by impact: blocking interaction, accessibility, visual hierarchy, consistency, or polish. For each, record the location, observed issue, proposed correction and verification method. Prefer focused changes that preserve working behavior.

## Deliver
Provide an actionable summary and scores out of ten for visual direction, typography, layout, responsive behavior and accessibility. Explain limitations where a check could not be performed.

# Design craft playbook

Use selectively for ambitious website concepts, visual refinement, or design systems. This is original guidance synthesized from reviewed design principles. It is a text-only reference.

## Match design to the visitor's objective

| Surface | Main objective | Visual approach |
| --- | --- | --- |
| Local business | Find the offer, visit or book | Photography of the place and offer, direct practical information, clear next action |
| Professional service | Understand expertise and request help | Relevant work and people, evidence-backed differentiators, readable editorial structure |
| Physical product | Evaluate the product and decide | Product at useful scale, detail views, context of use, clear specifications |
| Software | Understand or use the product | Representative interface, meaningful diagrams, restrained motion |
| Portfolio or gallery | Experience the work | Strong imagery, intentional sequence, unobtrusive navigation |
| Dashboard or documentation | Complete a task or learn | Legibility, predictable interaction, consistency and efficient scanning |

Choose imagery that matches the subject. Label conceptual or placeholder imagery when needed. Use original or appropriately licensed assets and verified business information.

## Visual composition

- Establish a shared alignment grid and balanced outer margins. Break the grid intentionally for emphasis.
- Give each section one main communication purpose. Let content determine height rather than forcing viewport-sized sections.
- Vary section compositions while keeping the typography, spacing and color system coherent.
- Present the actual subject at useful scale, with distinct views instead of repeating the same hero image.
- Reserve the strongest visual moment for a meaningful part of the story. Use subtle interaction feedback and respect reduced-motion preferences.
- Choose effects to suit the brand and the visitor's needs; prioritize photographs for businesses with physical places or products.

## Document the design

For a new site or substantial redesign, record the agreed visual direction in a project-specific DESIGN.md when useful. Include audience, surface objective, palette with semantic roles, type hierarchy, spacing scale, grid, component states, image direction, motion preferences and responsive behavior. Record exceptions for particular pages without unnecessarily changing the shared system.

Use public design examples to study general principles such as hierarchy, spacing and composition. Develop a distinct identity suited to the client's brief.

## Refine and verify

- For a polish request, retain the established identity, factual content and working interactions. For a redesign, preserve functional and business requirements while exploring a new visual direction.
- Consider the visitor's task before adding visual complexity. Simplify unclear interfaces and strengthen weak hierarchy.
- Review rendered results at 375, 768, 1024 and 1440 CSS pixels, and relevant intermediate widths.
- Use 44 by 44 CSS pixels as a comfortable touch-target design goal where practical; evaluate applicable WCAG AA requirements separately.
- Check contrast, semantic controls, focus, zoom, image dimensions, loading feedback, field-level errors and content wrapping.
- Assess motion, typography, alignment, visual consistency and performance. Report evidence separately from subjective design judgments.
- Prioritize corrections by user impact, then recheck affected views using available authorized project tools.

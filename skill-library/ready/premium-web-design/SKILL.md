# Premium web design

Use when planning or building a new marketing site or a substantial redesign.

## Direction
- Identify the business, audience, service, verified differentiators and desired visitor action.
- Choose a visual direction suited to the business, with a short rationale. Explore two distinct compositions when useful.
- Define a coherent palette, typography roles, spacing scale, image treatment and interactive states.
- Favor distinctive composition, strong hierarchy, readable copy and purposeful imagery. Avoid repeating the same layout across unrelated businesses.
- Prefer simple, maintainable HTML and CSS for straightforward sites. Choose additional complexity when the project benefits from it.

## Build
- Make the primary action clear, with useful content before decorative elements.
- Design for widths of 375, 768 and 1440 CSS pixels; check intermediate sizes as well.
- Use relevant, rights-cleared imagery, descriptive alternative text where appropriate, efficient WebP assets and stable image dimensions.
- Aim for WCAG AA contrast, semantic landmarks, keyboard access, visible focus, labeled controls and reduced-motion support.
- Keep commercial claims, reviews, pricing, locations and credentials grounded in information provided or verified.
- Preserve approved brand elements, contact routes and content in both languages. Write concise idiomatic copy for the intended market.
- Plan page titles, descriptions, social previews, meaningful heading hierarchy and relevant legal notices.

## Handoff
Summarize the art direction and key decisions. Review desktop and mobile rendering, interaction states, performance and accessibility using available project tools. Report measured results separately from design judgment. Identify remaining issues and score composition, typography, imagery, usability and technical quality out of ten with short explanations.
